    • PM 부품: 장비마스터 엑셀의 PM부품 시트(열 구분·타입·작업항목·부품명·수량(대당)·단위·비고)를 읽습니다. 현재 등록: T/C 엔진발전기 = 필터 교체, 윤활유 교체(수량 미입력). 항목이 없는 타입은 미등록(확인 필요)으로 둡니다.
    • 정기검사: 전 장비 2년(24개월) 1회. 최근검사일 = 정비유형 정기검사·법정검사 + 상태 완료 중 가장 늦은 날짜, 검사기한 = 최근검사일 + 24개월(2/29 → 2/28). 검사기한 < 주 시작일 → 기한 초과 · 이번 주 → 이번 주 기한 · 주 시작일 + 60일 이내 → 기한 임박. 유예 0일·임박 60일은 가정값, 확인 필요.
