# 주간 PM 도래 장비 자동 추출기 (Quick Win)

매주 월요일 30~60분 걸리던 "점검 도래 장비 찾기"를 자동화한다. 계획일과 입항 일정 배정은 사람이 한다.

## 폴더 구조
| 경로 | 내용 |
|---|---|
| `입력/장비마스터.xlsx` | **실제** 보유 장비 42대와 PM 주기 (2026-11-19 확인) |
| `입력/PM이력_가상.xlsx` | **테스트용 가상** 정비 이력 141행. 의도한 오류 케이스 4개 포함 |
| `make_inputs.py` | 위 두 입력 파일 생성 |
| `pm_due.py` | 추출기 본체 |
| `verify.py` | 독립 검산 + 경계값 테스트 |
| `출력/주간PM계획_YYYY-Www.xlsx` | 시트 7개: 주간PM계획(초안) · 이번주 부품 준비 · 다음주 예고 · 확인 필요 · 전체 현황 · 정기검사 · 판정 기준 |
| `출력/주간PM요약_YYYY-Www.md` | 보고용 요약 |
| `../.claude/skills/weekly-pm-due/` | 스킬. 새 대화에서 "이번 주 PM 대상 장비 뽑아줘"라고 요청 |

## 웹 현황판 (`웹/index.html`)
`웹/index.html`을 더블클릭해 브라우저로 연다. 설치는 필요 없고, 외부로 데이터를 보내지 않는다.
- 기본 데이터(실제 장비 42대 + 가상 이력)가 HTML 안에 들어 있다.
- 주 이동(이전 주/다음 주/날짜 선택). 월요일이 아닌 날을 고르면 그 주 월요일로 맞춘다.
- 장비마스터·정비이력 엑셀을 올리면 그 데이터로 다시 계산한다. 이때 엑셀 읽기 라이브러리를 인터넷(CDN)에서 받는다.
- 계획일·입항 일정 확인을 입력하면 이 브라우저에 주별로 저장된다.
- 엑셀로 내보내기: 계획일을 포함한 5개 시트. 라이브러리를 못 받으면 계획표만 CSV로 내보낸다.
- 장비 현황 맵: 42대를 타입별 타일로 보여 주고, 타일을 누르면 상세(PM·작업항목·정기검사)가 보인다. 정기검사 초과·임박·이력 없음 장비에는 `검` 표시가 붙는다.
- 계획표 `PM 작업항목` 열, `이번 주 PM 부품 준비` 카드, `정기검사` 카드(검사 신청일 입력·브라우저 저장)가 있다. 내보내기 엑셀에도 `이번주 부품 준비`·`정기검사` 시트가 들어간다.
- 장비마스터 엑셀을 올리면 `PM부품` 시트와 `정기검사주기(개월)` 열도 함께 읽는다.
- 데이터를 바꿔 다시 만들려면 `python 웹/build_web.py`(웹/index.html과 루트 index.html을 함께 갱신), 판정 대조는 `python 웹/verify_web.py`(Node.js 필요)를 실행한다.

## 실행
```
cd 13_PM도래추출기
..\.venv\Scripts\python.exe pm_due.py --master 입력\장비마스터.xlsx --history 입력\PM이력_가상.xlsx --week-start 2026-11-16
..\.venv\Scripts\python.exe verify.py 2026-11-16
```
`--week-start`를 생략하면 이번 주 월요일 기준으로 실행한다.

## 판정 규칙
- 최근PM일 = 정비유형 `PM` + 상태 `완료` 기록 중 가장 늦은 날짜
- 도래일 = 최근PM일 + 주기
- 유예기한 = 도래일 + 7일 (**가정값, 확인 필요**)

| 조건 | 상태 |
|---|---|
| 유예기한 < 주 시작일 | 주기 초과 |
| 도래일 < 주 시작일 ≤ 유예기한 | 도래(유예 중) |
| 도래일이 이번 주 안 | 이번 주 도래 |
| 도래일이 다음 주 안 | 다음 주 도래 (예고) |

다음 경우는 판정에서 빼고 `확인 필요` 시트로 보낸다.
- 완료 PM이 없음
- PM이 진행중
- 장비마스터에 없는 호기
- 주 시작일보다 늦은 날짜

## PM 작업항목·부품 (2026-11-26 추가)
`입력/장비마스터.xlsx`의 `PM부품` 시트에 구분·타입별로 작업항목을 한 줄씩 적는다.

| 구분 | 타입 | 작업항목 | 부품명 | 수량(대당) | 단위 | 비고 |
|---|---|---|---|---|---|---|
| T/C | 엔진발전기 | 필터 교체 | 필터 | (빈칸) | 개 | 필터 종류·수량 확인 필요 |
| T/C | 엔진발전기 | 윤활유 교체 | 윤활유 | (빈칸) | L | 규격·교체량 확인 필요 |

- 타입 값은 `장비마스터` 시트와 똑같이 쓴다(G/C는 `-`, T/C는 `엔진발전기`·`전기`).
- 계획표에 `PM 작업항목` 열이 붙고, `이번주 부품 준비` 시트와 요약 md에 타입별 **합계 수량 = 대당 수량 × 이번 주 대상 대수**가 나온다.
- 수량이 빈칸이면 합산하지 않고 "대당 수량 미입력(확인 필요)"으로 표시한다. 항목이 없는 타입은 "미등록(확인 필요)"이다.
- 현재 G/C·전기 T/C 항목은 미등록이다.
- ⚠ `make_inputs.py`를 다시 실행하면 장비마스터가 새로 만들어진다. 엑셀에서 직접 채운 항목을 지키려면 `make_inputs.py`의 `PM_PARTS`에도 같이 적는다.

## 정기검사 (2026-11-26 추가)
- 주기: **2년에 1회, 전 장비 동일** (장비마스터 `정기검사주기(개월)` = 24, 열이 없으면 24로 본다)
- 최근검사일 = 정비유형 `정기검사` 또는 `법정검사` + 상태 `완료` 기록 중 가장 늦은 날짜
- 검사기한 = 최근검사일 + 24개월 (같은 월·일. 2/29는 2/28)
- 유예 0일, 임박 기준 60일 (**둘 다 가정값, 확인 필요**)

| 조건 | 상태 |
|---|---|
| 검사기한 < 주 시작일 | 기한 초과 |
| 검사기한이 이번 주 안 | 이번 주 기한 |
| 검사기한이 주 시작일 + 60일 이내 | 기한 임박 |

결과는 엑셀 `정기검사` 시트(42대 전체, 검사 신청일 입력 칸 포함)와 요약 md의 `정기검사` 섹션에 나온다.
검사 이력 없음·검사 진행중도 `확인 필요`로 보낸다. 가상 이력의 테스트 케이스: 189호·186호 기한 초과, 274호 이번 주 기한, 431호 이력 없음, 186호 진행중.

## 실제 업무에 쓰려면
1. 실제 정비 이력(CMMS 내려받기 또는 대장 엑셀)의 열 이름을 `정비일자 / 호기 / 정비유형 / 상태`로 맞춘다. 다르면 스킬이 매핑을 묻는다.
2. 유예 기간 7일과 정비유형 표기(PM, 예방정비, 정기검사, 법정검사 등)를 실제 기준으로 확인한다. 정기검사 유예·임박 기준도 확인한다.
3. 처음 몇 주는 기존 수작업 결과와 나란히 비교한다.
